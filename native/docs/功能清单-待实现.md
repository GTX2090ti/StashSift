## 二、仍然缺失的功能（按影响排序）

### 1. 识别（Identify）— **未做**
- Flutter：`identify_page.dart`（用刮削器批量识别，逐条确认）
- 原生：只有 `StashApi.identifyScenes()`，**没有任何页面调用它**
- 影响：无法批量「让 Stash 猜这是哪部片」

### 2. 刮削器包管理 — **未做**
- Flutter：`scraper_packages_page.dart`（安装/更新/卸载社区刮削器包）
- 原生：只能选已装好的刮削器，不能装新的
- 影响：想加新站点刮削器必须去 Stash 网页端

### 3. 服务器设置独立页 — **未做**
- Flutter：`server_settings_page.dart`（改地址、ApiKey、超时、TLS）
- 原生：只有登录页能填一次，之后改地址要重新登录

### 4. 诊断页 — **未做**
- Flutter：`diagnostics_page.dart` + `api/net_health.dart`（连接健康度、耗时、失败原因）
- 原生：只有 `NetLogPage` 看请求日志，没有健康检查与耗时统计

### 5. 画廊 / 图片模块 — **未做**
- Stash 有 `galleries`（图集）与 `images` 两个实体
- 原生完全没有，只处理 scenes

### 6. 场景标记（Markers） — **未做**
- 时间点 / 章节标记，原生没有

### 7. 发布记录 / 版本信息 — **未做**
- Flutter：`releases_page.dart`（读 GitHub Releases 显示更新日志）

### 8. 文件 / 路径管理 — **未做**
- `moveFiles`、`fileRename` 都没接，不能重命名/移动文件

### 9. 备份 / 导出 — **未做**
- `metadataExport` 未接

### 10. Stash-Box 关联 — **未做**
- `submitStashBoxSceneDraft` 未接

### 11. 链接不可点击 — **部分**
- 演员 / 工作室 / 集合的 urls 目前只展示文本，点了没反应
- 修法：`UIAbilityContext.openLink(url)`（API 12+ 已确认存在），约 20 行

### 12. 多语言 — **部分**
- `settings/L10n.ets` 有框架，界面文案仍以硬编码中文为主
- 缺口：英文 / 日文界面

### 13. 短片详情的文件技术信息 — **部分**
- 有：分辨率、时长、大小、修改时间
- 缺：创建/更新时间、帧率、码率、视频编码、音频编码

### 14. 去重的「连文件一起删」— **未做**
- 有风险，未开放；需要二次确认 + 显式勾选

### 15. 手动任选两条短片合并 — **部分**
- 详情页支持「与另一条合并」（选择目标），但列表页没有多选合并入口

## 四、体验层面的欠账

| 项 | 现状 | 建议 |
|---|---|---|
| **合并候选列表** | 标签/演员合并第 2 步把 100+ 候选平铺，要滑 **18 屏** 才够到「下一步」 | 改固定高度可滚动列表 + 底部固定操作条（P0，v1.0.7 真机点检发现） |
| 编辑面板 + 键盘 | 输入时键盘盖住底部「保存」，要先收键盘（演员 20 字段最明显） | 加 `keyboardAvoidMode` 或把操作行固定在底部 |
| 合并面板的目标名 | 用打开面板时的名字快照，实体在别处改名后显示旧名 | 每次进面板重新取名字 |
| 封面加载 | 全部走网络直连，无本地缓存 | 加图片缓存，减少列表滚动时的重复请求 |
| 列表滚动位置 | 从详情返回后重置到顶部 | 记住滚动位置 |
| 搜索历史 | 无 | 记录最近搜索词 |
| 空状态引导 | 部分页面只有一行文字 | 补图标 + 操作按钮 |
| 长按菜单 | 仅详情页支持复制 | 列表页长按出快捷菜单 |
| 加载骨架屏 | 只有转圈 | 用骨架屏替代 |
| 错误提示 | Toast 一闪而过 | 可重试的卡片式错误 |
| 编辑面板很长 | 演员 20 字段、集合 10 字段，键盘遮挡未专项处理 | 加 `keyboardAvoidMode` / 分组折叠 |

## 五、建议的优先级

| 优先级 | 功能 | 理由 |
|---|---|---|
| P0 | 链接可点击 | 成本极低（`openLink`），体验缺口明显 |
| P0 | 真机逐项点检 v1.0.7 的编辑/合并链路 | 本轮只过了编译与静态检查 |
| P1 | 识别（Identify） | 功能强，交互复杂，需要单独设计 |
| P1 | 服务器设置独立页 | 换地址/换密钥不用重登 |
| P2 | 刮削器包管理 | 一年装不了几次 |
| P2 | 多语言落地 | 有框架，缺翻译与切换器 |
| P3 | 画廊 / 图片、Markers、备份 | 大模块，另起一轮 |
| — | 视频播放 / 工作室合并 | 已排除（后者服务器不支持） |
