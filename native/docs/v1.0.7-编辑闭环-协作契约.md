## 2. 本轮已就绪的 API（Lead 已写入并编译通过）

导入：`import { StashApi } from '../api/StashApi'`；模型：`import { PerformerUpdate, TagUpdate, StudioUpdate, GroupUpdate, ... } from '../models/Models'`。

```ts
// ── 演员 ──────────────────────────────────────────────
updatePerformer(id: string, u: PerformerUpdate): Promise<boolean>
mergePerformers(sourceIds: string[], destinationId: string): Promise<boolean>   // sourceIds 并入 destination

// PerformerUpdate 字段（都是整表写回；空串=清空该字段）
name, disambiguation, aliases: string[], urls: string[], gender: string(空=不改),
birthdate, death_date, country, ethnicity, hair_color, eye_color,
height_cm: number, weight: number, measurements, fake_tits, tattoos, piercings,
career_start, career_end, details
// 构造：PerformerUpdate.from(performer: Performer) 会带出当前值，直接改字段再保存

// ── 标签 ──────────────────────────────────────────────
updateTag(id: string, u: TagUpdate): Promise<boolean>
mergeTags(sourceIds: string[], destinationId: string): Promise<boolean>
createTag(name: string): Promise<string>            // 已有，返回新 id（空串=失败）
// TagUpdate: name, sort_name, description, aliases: string[], favorite: boolean,
//            parentIds: string[], setParents: boolean（true 才覆盖父标签）
// 注意：TagDto 里父标签是 parents?: TagDto[]

// ── 工作室 ────────────────────────────────────────────
updateStudio(id: string, u: StudioUpdate): Promise<boolean>
// StudioUpdate: name, aliases: string[], urls: string[], details, favorite: boolean,
//               rating100: number, organized: boolean, parentId: string, setParent: boolean
// 服务器没有 studioMerge，本轮不做工作室合并

// ── 集合 Group ────────────────────────────────────────
createGroup(name: string): Promise<string>          // 返回新 id
updateGroup(id: string, u: GroupUpdate): Promise<boolean>
destroyGroup(id: string): Promise<boolean>
findGroupsRich(page, perPage, sort, direction, q): Promise<GroupDto[]>   // 带封面/数量/日期/工作室/标签
findGroup(id): Promise<GroupDto | null>             // 已含 urls / studio / tags
// GroupUpdate: name, aliases: string(注意是字符串), date, duration: number, rating100: number,
//              director, synopsis, urls: string[], studioId: string, setStudio: boolean,
//              tagIds: string[], setTags: boolean

// ── 短片 ──────────────────────────────────────────────
setSceneGroups(sceneId: string, groupIds: string[]): Promise<boolean>   // 覆盖式，空数组=清空
findScene(id) 现在会返回 groups（模型 Scene 上新增 groupIds / groupNames 两个数组）
```

**写操作错误处理**：这些方法在服务端返回 GraphQL 错误时**抛 `ApiException`**，`message` 就是 Stash 的原因（如 `tag with name "x" already exists`）。页面里一律：

```ts
try {
  await this.api().updateTag(this.id, u)
  this.say('已保存')
} catch (e) {
  this.say('保存失败：' + (e as Error).message)
}
```

## 3. UI 约定（必须与现有页面一致）

- 页面根：`Column()` + `.linearGradient(...)`（用现有 `this.bd`）+ `.expandSafeArea(...)`，**照抄同页面现有写法**。
- 顶栏：`GlassNavBar({ title, subtitle, theme: this.theme, ... })`。
- 卡片：`GlassCard({ style: GlassStyle.ULTRA_THIN | REGULAR, title, theme: this.theme }) { ... }`。
- **编辑面板**：参考 `pages/SceneDetailPage.ets` 的 `editCard()`（约 666-980 行）——进编辑时把内容区换成表单，顶部一行「取消 / 保存」，输入用：

```ts
TextInput({ text: this.editName, placeholder: '名称' })
  .fontSize(14).height(40).layoutWeight(1)
  .backgroundColor(this.theme.chipBg)
  .fontColor(this.theme.textPrimary)
  .placeholderColor(this.theme.textSecondary)
  .borderRadius(RADIUS_CHIP)
  .padding({ left: 10, right: 10 })
  .onChange((v: string) => { this.editName = v })
```

- 多行：`TextArea({ text, placeholder })`，`.height(80)` 起步。
- 主按钮：`Button('保存').fontSize(14).height(40).backgroundColor(this.theme.brandColor).fontColor(Color.White)`；次按钮透明底 + `this.theme.chipBg`。
- 列表选择（如父标签、所属集合、合并目标）：做一个**页面内浮层**（`Stack` 里 `if (this.pickMode.length > 0) { ... }`），带搜索框 + 列表 + 取消，参考 `SceneDetailPage.pickerPanel()`。候选项可复用 `common/OptionCache.ets` 的 `loadOptions(api, mode)`（mode: `'studio' | 'performer' | 'tag'`），集合列表用 `api.findGroupsRich(1, 300, 'name', 'ASC', '')`。
- toast：沿用页面已有的 `say(msg)` / `this.toast` 机制（有就复用，没有就加一个 3 秒自动清的 `@State toast`）。
- 保存成功后：调用 `bumpScenes()`（`import { bumpScenes } from '../common/DataVersion'`）让列表刷新，并 `await this.load()` 重新拉当前页数据。

## 4. 交互要求（每个实体一致）

- 只读态：详情页操作行加「编辑」按钮；列表页顶栏或卡片上给「新建」（标签/集合）。
- 编辑态：字段预填当前值 → 改 → 保存；失败留在编辑态并提示原因。
- 破坏性操作（删除集合、合并）必须**二次确认**（参考 `SceneDetailPage.confirmDelete()` 的确认浮层写法）。
- 合并：先选「保留哪个（目标）」，再列「并入哪些（可多选）」，确认后调 merge；成功后返回目标详情并刷新。
- 空值展示：`—`。
