## 一、连接与安全

| 功能 | 说明 | 实现位置 |
|---|---|---|
| 服务器登录 | 填写 Stash 地址 + ApiKey，连接测试后保存 | `pages/LoginPage.ets` |
| 启动路由 | 未登录 → 登录页；已开锁 → 锁屏页；否则首页 | `entryability/EntryAbility.ets` |
| 应用锁 | 人脸 / 指纹解锁（ATL3），失败停留锁屏 | `pages/LockPage.ets`、`common/Biometric.ets` |
| 切后台上锁 | 退到后台再回来需要重新验证 | `EntryAbility.needLock / lockNow()` |
| 多任务隐私模糊 | 后台时系统多任务卡片内容模糊 | `EntryAbility.applyPrivacy()` → `setWindowPrivacyMode` |
| 安全模式 | 隐藏敏感内容（封面/标题打码），设置页可开关 | `AppStorage 'safeMode'` |
| 全局错误日志 | 未捕获异常写 hilog，tag `StashGo-Error` | `common/ErrorLog.ets` |
